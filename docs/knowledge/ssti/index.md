# SSTI 模板注入

> **一句话：用户输入被当成了模板源码，于是 `{{ }}` 里的东西由服务器替你执行。**

## 核心模型

```text
入口:  搜索框 / 用户名 / 留言 / URL 参数
  ↓
拼接:  render_template_string("hello " + name)
  ↓
求值:  Jinja2 把 {{ }} 里的表达式交给 Python 算
  ↓
走到执行: 字符串 → 类 → 父类 → 所有子类 → 模块全局 → import → 命令
```

**和 SQL 注入是同一个道理：数据越界变成了代码。**区别只是越界的"语言"不同——SQL 里逃出引号，模板里逃出 `{{ }}`。

## 最常用的三条

```jinja
{{7*7}}                     探测：回显 49 说明模板被执行
{{config}}                  确认 Flask，有时直接读到 SECRET_KEY
{{url_for.__globals__}}     短链入口：函数身上挂着模块全局空间
```

## 卡住时的三问

```text
① 是空白，还是 500？
   空白 = 取不到（名字不存在 / 下标越界 / 值是空）
   500  = 取到了，但对它做了非法操作

② 这个名字在模板里存在吗？
   只有 config / request / session / url_for / lipsum / dict / range 这些
   str / int / object 不在，得从对象爬过去

③ 这一段是"形状"被拦，还是"词"被拦？
   .__globals__ 被拦 → |attr('__globals__') 换形状
```
