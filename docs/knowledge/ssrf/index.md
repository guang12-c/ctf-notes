# SSRF

> **一句话：应用拿你的输入去发请求，于是你能让它去请求它自己才够得着的地方（内网、本机、云元数据）。**

## 这条线的核心

```text
入口:  URL / 域名 / 图片地址 参数
       (url=、target=、image=、webhook=、feed=)
  ↓
行为:  file_get_contents($_GET['url'])
       curl_exec()、requests.get()、new URL().openConnection()
  ↓
利用:  url=http://127.0.0.1:5001/api/debug?cmd=id
       url=http://169.254.169.254/latest/meta-data/
```

## 和路径遍历的区别

| | 路径遍历 | SSRF |
|---|---|---|
| 谁去拿数据 | 应用**读文件** | 应用**发请求** |
| 撞到的边界 | 目录 | 网络（本机 / 内网 / 元数据） |
| 典型失败 | `../` 被过滤 | `127.0.0.1` 被过滤 |
| 共同点 | **都是「服务端替你去做事」，而它做的事不该由用户指定** | |
