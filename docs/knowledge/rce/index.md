# RCE

## 两部分，别混

| | 执行什么 | sink | `;` 的含义 |
|---|---|---|---|
| **命令注入** | 系统命令 | `system` / `exec` / 反引号 | 命令分隔符 |
| **代码执行** | PHP 代码 | `eval` / `assert` | 语句结束符 |

**判断方法：** 发 `echo(123);` —— 出 123 是代码执行，发 `;id` —— 出 uid 是命令注入。
