# [NewStarCTF] So Baby RCE —— 子串黑名单 + 没有斜杠

## 源码

```php
if(preg_match('/et|echo|cat|tac|base|sh|more|less|tail|vi|head|nl|env|fl|\||;|\^|\'|\]|"|<|>|`|\/| |\\\\|\*/i', $_GET["cmd"])){
   echo "Don't Hack Me";
}else{
    system($_GET["cmd"]);
}
```

## 先分类这个黑名单

| 类别 | 被封 | 后果 |
|---|---|---|
| 命令名 | `cat` `tac` `head` `tail` `more` `less` `nl` `vi` | 常见读文件命令全灭 |
| **子串** | `et` `sh` `fl` `base` `env` | **`get`/`set`/`bash`/`flag` 全被连坐** |
| 路径 | `/` | 不能用绝对路径 |
| 空白 | 空格 | 必须 `$IFS` |
| 重定向 | `\|` `;` `<` `>` `` ` `` | 只能靠 `&&` |
| 通配 | `'` `"` `]` `\` `*` `^` | 不能包字符串、不能用 `*` |

## 过程

```text
① ls                    → 当前目录是个没用文件
② cd$IFS..$IFS&&ls      → 一级一级往上爬(因为 / 被禁)
③ 在根目录找到 flag
④ sort 或 grep 读内容
⑤ 但 flag 里含 fl → 被拦
⑥ 用 ? 当通配符 → 绕过
```

## 卡点与绕法

| 卡点 | 绕法 | 原理 |
|---|---|---|
| 空格被禁 | `$IFS` | IFS 默认含空格 |
| **`/` 被禁** | **`cd ..` 逐级爬** | 相对路径不含 `/` |
| `\|` `;` 被禁 | `&&` | 逻辑与还能串命令 |
| `*` 被禁 | `?` | `?` 没在黑名单里 |
| `cat/head/tail` 被禁 | `sort` `grep` `uniq` `od` `strings` `awk` `sed` | 读文件的替代品一大堆 |
| `fl` 被禁 | `fl?ag` | 通配符替你补字符 |

## sort 和 grep 的区别

| | `sort` | `grep` |
|---|---|---|
| 用途 | 排序 | 搜索 |
| 输出 | **所有行**（排序后） | **只输出匹配的行** |
| 要模式吗 | 不用 | **要**（`grep . 文件`） |
| 多行文件 | 全出但顺序变了 | 只出匹配的 |

**flag 只有一行时两个都行；多行文件时 `sort` 会重排、`grep` 会过滤。**

## 一个纠正

```bash
echo fl{abc}ag    →  fl{abc}ag     ← 原样,不是 flag
echo fl{,}ag      →  flag          ← 空选项才有效
```

**花括号展开只在 bash 下有效。这题真正能过的是 `?`。**

## 收获

> **黑名单是子串匹配时，先找"哪些常用词被连坐"（`et` 封掉 `get`/`set`）。**
>
> **`/` 被封不等于走不了 —— `cd ..` 相对路径一样能爬到根目录。**
>
> **读文件命令十几个，封 8 个还剩 8 个；`*` 被封还有 `?`。**
